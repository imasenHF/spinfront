# 维护约定

日报仅保留文本，不使用图片字段。摘要与技术评注采用中立表述；技术判断与原文结论分开，不补写未知参数。定时任务输出后将单期JSON放入data/YYYY/，由构建脚本统一生成HTML。

新ID先审查定义、同义词、维度及层级，发布词表新版本；每期标记taxonomy_version。父级检索包含同维度子标签；同维度OR，跨维度AND；谱学方向仅使用nmr和epr；同时涉及两者时记录两个ID。MRS归nmr与in_vivo_mrs；MRV测速归nmr与mr_velocimetry。单一核种不自动归多核，稳定探针不自动归捕获，常规硬件不产生部件标签。

新增信息类型news_feature、funding_facility、research_integrity需同步定时项目的枚举规则。来源核验独立记录，tag_review_status=approved仅代表分类判定。原始日期与历史时间范围保留，未全面复核。重复候选在历史变更材料中保留，不能根据会议共用URL直接删条。

本仓库承担内容与发布；主站只需提供入口链接。日报路径固定，后续主页改版不改变日期网址。

## 词表1.1.0及页面检索

方向默认多选OR，可选择仅同时涉及NMR与EPR。旧链接nmr_epr转换为双方向AND；mrs与mrv分别转换为NMR方向加对应实验类型。UI方法分组只用于展示，不作为正式标签。组内保留原有父子检索关系。新增方法须同步ui_groups，构建时检查所有根标签恰好出现一次。

迁移日志记录变更前后ID；本次分类调整不代表原始来源或日期已经复核。

## 词表1.2.0与检索设计

应用领域使用展示层分组 application_domains，不把界面分组ID写入单期记录。现有研究对象涵盖化学结构与反应、生命科学与药物、能源与电化学、材料与聚合物、食品与农业、环境与地学、文化遗产、分析检测与工艺、量子自旋与传感；仪器技术独立保留。该分类覆盖当前归档，不代表穷尽所有应用。临床波谱、农业子领域、其他质量控制子领域等按实际出现的研究内容再新增受控子标签；代谢组学等方法可与应用交叉检索，不能据方法自动推断研究对象。

采购、教育培训不再作为应用ID：采购由tender或funding_facility表达，培训通常归event；已有科普和应用说明保留实际信息类型，不能强行改成活动。旧采购链接映射信息类型；旧教育链接宽映射event/news_feature/application_note，不保证等价历史训练标签集合。父子关系修复材料—聚合物、化学结构—天然产物/无机配位。新增quantum_spin有明确纳入边界。修改依据及前后值见taxonomy-migration-1.2.0.json。

主页方向使用全部/NMR/EPR三段切换，双方向限定在高级筛选；应用领域按钮可多选，同维度取并集。选择子应用时移除覆盖它的父标签，避免父标签抵消细化条件。高级筛选顺序为方法、实验类型、信息类型、部件，各维度显示已选数；长标签使用展开更多，不使用内部标签滚动区。预留页面及侧栏滚动条宽度，保留可见焦点、触摸尺寸和减少动态效果偏好。

日期按日报日期取闭区间；最近7天截至归档最新一期，本月对应日期定位组件当前月份。搜索URL携带条件及卡片/列表视图。主题快捷入口重置原有条件以避免隐含冲突。日历日期只定位已有日报；来源日期独立显示。完整归档使用年份选择、月份按钮和直接日期入口，不再嵌套周目录。手机采用单列日期列表。

阅读位置在当前浏览器会话内保存；返回归档时恢复URL条件、加载数量、页面与侧栏位置。来源性质仅使用明确publication_status，或已有product_software/application_note/tender信息类型；unknown论文不冒充正式出版。历史381条均缺少publication_status，不批量推定。后续有来源核验才补写preprint/early_access/published。

quality_control覆盖质量控制、认证标准物质及计量溯源；现有两条qNMR/CRM记录提供新增依据，不因使用qNMR自动添加此应用。日期定位默认收起以优先显示应用筛选，可随时展开日历与日期范围。
